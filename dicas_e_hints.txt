Atenção importante

Para UPDATE, DELETE e MERGE, garanta que a tabela esteja em Iceberg format-version 2, porque operações de row-level DML dependem de recursos de V2 em muitas engines.

Na criação das tabelas, eu adicionaria:

TBLPROPERTIES (
  'format-version' = '2',
  'write.format.default' = 'parquet',
  'write.delete.format.default' = 'parquet'
)

No Spark:

spark.sql("""
CREATE TABLE governo_mg.beneficios (
    id_cidadao BIGINT,
    nome STRING,
    valor_beneficio DOUBLE,
    data_pagamento DATE,
    status STRING
)
USING iceberg
TBLPROPERTIES (
    'format-version' = '2',
    'write.format.default' = 'parquet',
    'write.delete.format.default' = 'parquet'
)
""")
